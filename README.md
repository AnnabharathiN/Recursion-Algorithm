# Recursion & Algorithms — JavaScript

A collection of algorithm exercises implementing both 
recursive and iterative solutions in JavaScript, completed 
as part of the Full Stack MERN Developer Bootcamp 
at Matrix Master, Rotterdam.

## Algorithms Covered

### Recursion
- **BunnyEars** — counting bunny ears using recursion
- **Triangle** — calculating triangle numbers recursively
- **PowerN** — calculating power of N recursively

### Recursive vs Iterative comparison
- **Fibonacci sequence** — comparing recursive and 
  iterative approaches
- **Factorial** — comparing recursive and iterative 
  approaches with HTML visualization

## What I learned

- Understanding recursion — base case and recursive case
- Comparing recursive vs iterative solutions
- Algorithm complexity and performance differences
- Pure JavaScript function design
- Visualizing algorithm output in HTML

## Technologies Used

- JavaScript (ES6+) — algorithm logic
- HTML5 — factorial visualization

## How to run

1. Clone the repository
2. Open any .js file in your browser console or Node.js
3. Open R&I-Factorial.html in your browser to see 
   the factorial visualization
